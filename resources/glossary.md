**Application Programming Interface (API)** - A way of interacting with another computer/server so that you can retrieve data from their system. For example, you can use Spotify's API to download data from them about playlists, artists, albums etc.

**Integrated Development Environment (IDE)** - Software that helps you to code by providing things like a script editor, debugger, version control etc. Popular ones are VSCode, Spyder, and PyCharm.

**Operating system (OS)** - Simply put, the program that runs your computer, e.g. Windows, OSX (for Mac), Linux... These are the main categories but there are variations of each, e.g. Windows 7, Windows 10, Windows 11 etc...

**The terminal** - aka The command prompt, aka The shell. A text-based progrtam that allows you to directly interact with the computer's OS. Everything that you normally do by clicking windows can, in theory, be done in the terminal (e.g. opening programs, navigating folders, copying and pasting files etc etc etc).
