## Application Programming Interface (API)

A way of interacting with another computer/server so that you can retrieve data from their system. For example, you can use Spotify's API to download data from them about playlists, artists, albums etc.

## Array

A structured list or collection of items stored together, usually all of the same type. Think of it like a row of boxes where each box holds one value.

## Command

An instruction you give to a computer, often typed into a terminal or script. A command tells the computer to do something specific, like move a file or run a program.

## Function

A named set of instructions that performs a particular task. Functions are useful because you can use the same instructions many times without rewriting them. The term [Method](#method) may also be used when it is a function that belongs to an *object*. See the [Method](#method) entry for more description.

## Method

A method is a type of function that is attached to a specific object or data item. It tells that object how to do something, such as sorting itself, reading data, or changing its contents. In simple terms, a method is a built-in instruction for a particular thing. So, for example, *append* is a method that belongs to the object *list* and allows you to add an item to it.

## Kernel

In everyday computer science, a kernel is a small program that acts like the brain or manager of a system. In an [Operating system (OS)](#operating-system-os), it manages memory, running programs, and hardware. In a [Notebook](#notebook), the kernel is the live Python process that actually runs the code in the notebook. When a notebook kernel is "running", it is executing your code. If it "dies" or needs to be restarted, that means the Python process stopped or got confused, so the notebook has to start a fresh one to continue working.

## Integrated Development Environment (IDE)

Software that helps you to code by providing things like a script editor, debugger, version control etc. Popular ones are VSCode, Spyder, and PyCharm.

## Interpreter

A program that reads code and runs it one step at a time, translating it into instructions the computer can understand as it goes.

## Language

In computing, a language is a way to tell a computer what to do. A programming language is a set of rules and words that humans use to write instructions for a computer.

## Library

A collection of pre-written code that other programmers can reuse. Think of it like a toolkit or recipe book: instead of building everything from scratch, you can borrow ready-made tools.

## Notebook

A document that combines code, explanations, and the results of running code in one place. It is often used for data analysis, teaching, and experiments. The most common form for Python is a Jupyter Notebook. A notebook usually uses a [Kernel](#kernel) to execute the code that sits inside it.

## Operating system (OS)

Simply put, the program that runs your computer, e.g. Windows, OSX (for Mac), Linux... These are the main categories but there are variations of each, e.g. Windows 7, Windows 10, Windows 11 etc... This is different from a [Kernel](#kernel) in a notebook, which is the program running your Python code.

## Operation

A single action or task that the computer performs, such as reading a file, calculating a value, or saving data. In programming, it can also refer to a basic action like adding or comparing numbers. See also [Function](#function) and [Method](#method), which are ways of packaging operations into reusable instructions.

## Terminal

aka *The command prompt*, aka *The shell*. A text-based progrtam that allows you to directly interact with the computer's OS. Everything that you normally do by clicking windows can, in theory, be done in the terminal (e.g. opening programs, navigating folders, copying and pasting files etc etc etc). A terminal is often how you launch a [Kernel](#kernel), a program, or a script from the command line.
