# Workshop 4 - Data visualisation II

In this workshop, we will continue exploring data visualisation fundamentals using the Claus Wilkes book - https://clauswilke.com/dataviz/.

We'll spend time talking more specifically about different types of graphs that can be used to show different types of data including representation of amounts, distributions, and uncertainty.
