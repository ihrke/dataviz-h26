# Workshop 5 - Project management and version control

In this workshop, I introduced the reasons that good project management is important for your coding. It helps you and others to use the code effectively, contribute to new projects, and understand what you have done when you come back to a project after some time away from it.

Version control - exemplified by the tools Git and Github - is an essential part of tracking your code as well as collaborating and sharing with others. Uploading your project as a Github repository is an important element of the exam.

In the class, you should all have made a Github repository - either a test one or one for your project - and you should have been able to synchronize it with the cloud (remote) version. *If this wasn't working for anybody, then please let me know so that I can try to help you!*

We also had a brief look at README files. This is the most basic form of documentation for a project and something every project should have. I showed you the online editor/creator https://readme.so/editor. You can also use AI assistants to help produce a README for you. The README will be displayed on the home page of your Github repository. If you feel like being ambitious, you can add pictures and videos.
